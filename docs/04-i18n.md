# Languages
- All words live in `src/shared/i18n/en.js` and `hi.js`. No words inside components.
- Both files must have the same keys. A test checks keys, empty texts and {blanks}.
- Use `t('key')` or `t('key', { name: 'x' })`.
- A new language can be a partial file in `languages.js`. Missing keys fall back to English.
- The chosen language is remembered on the device (localStorage) and is not sent anywhere.
